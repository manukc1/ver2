QR File Transfer

Статическая версия для GitHub Pages

Без сервера передачи

1. Открой страницу на телефоне

QR-код содержит ссылку на эту страницу с кодом сеанса. Отсканируй его камерой телефона.
Не удалось загрузить QR-код.
Скопируй ссылку ниже.
Если QR не загрузился, открой ссылку вручную.
Создаём ссылку…
Важно: QR-код работает, передача пока нет. GitHub Pages не запускает сервер. Сканирование откроет эту же страницу на телефоне, но устройства не смогут автоматически обмениваться файлами.

2. Выбери файл на этом устройстве

Эта демонстрационная версия позволяет выбрать файл и получить локальную ссылку для скачивания на том же устройстве. Файл никуда не отправляется.

Ограничение статического сайта Чтобы передавать файл между телефоном и компьютером, понадобится сервер/облачная функция или отдельная P2P-связь с обменом данными подключения. QR-код сам по себе файл не передаёт.
Файлы остаются в памяти браузера и не загружаются на сервер этим приложением. QR-код генерируется внешним сервисом.
