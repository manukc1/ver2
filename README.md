# QR File Transfer

Веб-приложение для передачи файлов между компьютером и телефоном через QR-код. Работает в локальной Wi-Fi сети и через интернет, если оба устройства открывают одну и ту же ссылку сеанса.

## Возможности
- Передача в обе стороны: телефон ↔ компьютер.
- Файлы до 20 МБ каждый.
- QR-код и секретная ссылка сеанса.
- Список файлов и кнопка скачивания.
- Файлы хранятся в оперативной памяти сервера не более 10 минут и удаляются после скачивания.
- Внешние CDN для интерфейса не используются.

## Запуск на своём компьютере
1. Установи Node.js 18 или новее: https://nodejs.org/
2. Распакуй архив и открой терминал в папке `qr-file-transfer`.
3. Выполни:
   ```bash
   npm install
   npm start
   ```
4. На этом компьютере открой `http://localhost:10000`.
5. Чтобы подключить телефон в той же Wi-Fi сети, открой на телефоне `http://IP-АДРЕС-КОМПЬЮТЕРА:10000`. Узнать IP можно командой `ipconfig` в Windows; найди IPv4-адрес Wi-Fi адаптера. Разреши Node.js доступ в брандмауэре для частной сети.

## Бесплатный интернет-хостинг на Render
1. Создай аккаунт на https://github.com/ и новый репозиторий, например `qr-file-transfer`.
2. Загрузи в репозиторий все файлы и папку `public` из этого архива. Не загружай `node_modules`.
3. Открой https://render.com/ и создай аккаунт.
4. В панели Render нажми **New → Web Service**, подключи свой GitHub-репозиторий.
5. Укажи:
   - **Runtime / Language:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** Free
6. Нажми **Create Web Service** и дождись статуса **Live**.
7. Открой выданный адрес вида `https://имя-сервиса.onrender.com` на компьютере. QR-код появится автоматически. Отсканируй его телефоном.

## Важные ограничения
- Бесплатный Render может усыплять сервис после примерно 15 минут бездействия; первое подключение после простоя может занять около минуты.
- Файлы находятся только в памяти процесса. При перезапуске или пробуждении сервиса ещё не скачанные файлы могут пропасть. Не используй это приложение как постоянное хранилище.
- Каждый файл ограничен 20 МБ, а общий объём ожидающих скачивания файлов — примерно 50 МБ на экземпляр.
- Файл доступен любому, у кого есть секретная ссылка сеанса. Не публикуй QR-код и ссылку публично.
- Сервис предназначен для личного использования и не имеет аккаунтов или дополнительной парольной защиты. Для конфиденциальных файлов добавь PIN-код/авторизацию перед публичным использованием.
- В локальной сети каждый телефон должен открывать ссылку, указывающую на компьютер, а не `localhost`. Для доступа извне локальной сети используй опубликованный Render URL.

## Проверка
- Открой `/health` на адресе сервиса — должен вернуться `{"ok":true}`.
- Создай сеанс на компьютере, отсканируй QR телефоном, отправь небольшой файл и проверь, что он появился на другом устройстве.
