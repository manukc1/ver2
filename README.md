# QR File Transfer — GitHub Pages edition

Эта версия предназначена для публикации на GitHub Pages и не требует Node.js/Render.

## Установка

1. Открой репозиторий `https://github.com/manukc1/ver2`.
2. Нажми **Add file → Upload files**.
3. Загрузи файл `index.html` из этого архива **в корень репозитория**, рядом с `README.md`.
4. Нажми **Commit changes**.
5. В репозитории открой **Settings → Pages**.
6. Установи **Deploy from a branch**, ветка `main`, папка `/(root)`, нажми **Save**.
7. Подожди 1–3 минуты и открой `https://manukc1.github.io/ver2/` с обновлением страницы без кэша (Ctrl+F5).

## Что работает

- Интерфейс статического сайта.
- Создание уникальной ссылки сеанса.
- QR-код ссылки (изображение загружается с `api.qrserver.com`).
- Копирование/открытие ссылки.
- Выбор локального файла до 20 МБ и ссылка на скачивание этого же файла на текущем устройстве.

## Что НЕ работает

GitHub Pages — статический хостинг. Эта версия **не передаёт файлы между устройствами**. Когда телефон сканирует QR, он только открывает ту же страницу. Файлы не загружаются в облако и не появляются автоматически на компьютере.

Для настоящей передачи потребуется сервер/API (например, Cloudflare Workers с подходящим хранилищем) либо P2P-соединение WebRTC с отдельным способом обмена параметрами соединения. QR-код сам по себе не создаёт канал передачи.

## Приватность

Выбранный файл обрабатывается локально браузером. Ссылка QR-кода отправляется внешнему сервису генерации QR как параметр URL, чтобы получить изображение. Не используй ссылку с чувствительными данными.
